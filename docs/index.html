このツールは、既に通信設定済みの XBee を API モード（AP=1）と透過（AT）モード（AP=0）の間で切り替えるためのツールです。PAN ID、Coordinator/Router、宛先アドレス、通信ボーレート等の既存設定は変更しません。 現在モードの自動判定は行いません。必ず現在のモードに合う方向のボタンを選んでください。透過（AP=0）機にAPI→透過を実行すると、検出用APIバイナリが透過データとして扱われる可能性があります。

注意事項

            
適用範囲

          

        

        
    
          
  • 各ポートの現在の UART ボーレートを候補から自動検出します。ボーレート設定そのものは変更しません。
    • 
          
  • 透過（AT）→ API は +++、ATAP1、ATWR、ATCN を送信します。
    • 
          
  • API → 透過（AT）は検出用 0x09 AP query の後、設定フレームとして 0x09 AP=0、0x08 WRだけを送信します。ASCIIの ATAP0 は送信しません。
    • 
          
  • API → 透過は、このツールが作成した AP=1 のXBeeを対象とします。AP=2（エスケープAPI）は非対応です。
    • 
          
  • Chrome / Edge の HTTPS または localhost と、Web Serial 対応環境が必要です。
